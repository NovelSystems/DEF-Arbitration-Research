# Pole-fidelity battery

Status: WRITTEN, NOT RUN. Every run is a paid model run and needs Sam's approval first.

One fixed question per seat (8 seats). Each check is 1 `def-member` call with the seat's full first-pass envelope (verbatim prompt, any v0.2 envelope addendum, word limit, claims labels) and the question. No router, no arbiter. The report passes if it argues from the pole's charter in its reference file, at full strength, and does not drift toward the opposite pole or toward a third position.
